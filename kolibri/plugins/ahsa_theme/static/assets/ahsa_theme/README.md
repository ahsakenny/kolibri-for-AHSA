# AHSA Theme Assets

This directory contains placeholder branding assets for AHSA Learning Network.

## Required Assets

Replace these placeholder files with actual AHSA branding:

- `ahsa-logo.svg` - Main logo (SVG format, any size)
- `ahsa-logo-192.png` - Logo for PWA manifest (192x192 pixels)
- `ahsa-logo-512.png` - Logo for PWA manifest (512x512 pixels)
- `ahsa-favicon.ico` - Favicon for browser tabs (32x32 pixels)
- `ahsa-background.jpg` - Background image for login page (1920x1080 recommended)

## Branding Guidelines

When replacing these assets:
- Use AHSA brand colors: Navy Blue (#003366) and Orange (#FFA500)
- Ensure logos work on both light and dark backgrounds
- Optimize images for web (use compression)
- Test on multiple screen sizes and devices
- Maintain aspect ratios

## File Formats

- **SVG**: Preferred for logos (scalable, small file size)
- **PNG**: For raster logos and icons (with transparency)
- **ICO**: For browser favicon
- **JPG**: For background images (better compression than PNG)
